# prism-sketch-ann

> **Status: To be released.**
>
> This repository holds the working tree for *Prism: Contrastive Sketching for
> Approximate Nearest Neighbour Search* (NeurIPS 2026). The paper was accepted
> in the recent decision cycle, but the implementation is still being cleaned
> up and **the code will be published later**, after the camera-ready deadline.
> Please do not link to this repository from public pages yet.

## Layout

- `src/prism/` — sketch construction and index
- `configs/` — evaluation configurations
- `experiments/` — recall/latency drivers
- `data/` — pointers to the SIFT-1M split
